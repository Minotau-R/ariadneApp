# shinePath: interactively explore and cross the ariadne resource graph

shinePath launches a Shiny app to interactively explore and cross the
ariadne resource graph, effectively providing a simple alternative to
its programmatic access with ariadne and ariadnePy.

## Usage

``` r
shinePath()
```

## See also

- ariadne: <https://github.com/Minotau-R/ariadne>

- ariadneDB: <https://github.com/Minotau-R/ariadneDB>

- Zenodo: <https://zenodo.org/records/18788725>

## Examples

``` r
if( interactive() ){
    # Launch ariadne app
    shinePath()
}
```
